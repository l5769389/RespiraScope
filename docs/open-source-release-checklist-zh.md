# 开源发布检查清单

在把 RespiraScope 发布到 GitHub 前，建议按下面清单确认一次。

## 必须确认

- [ ] 仓库中没有真实患者数据、真实记录文件或可识别身份的信息。
- [ ] 仓库中没有真实设备 IP、内网地址、医院/客户名称、账号、密码、token 或密钥。
- [ ] 只提交 `config/breath.example.toml`，不提交生产配置。
- [ ] `README.md` 中的启动、配置、打包和测试命令可以在干净环境中执行。
- [ ] `uv sync` 可以安装依赖。
- [ ] `uv run pytest` 可以通过。
- [ ] `uv run RespiraScope` 可以启动后端和 Web Console。
- [ ] `.\scripts\build-exe.ps1` 可以生成 exe。
- [ ] README 中已经明确说明项目不作为医疗诊断或临床监护依据。
- [ ] LICENSE 已选择并提交，本项目使用 MIT License。

## 建议补充

- [ ] 为 README 添加 Monitor、模拟信号设置和记录分析截图。
- [ ] 准备一份完全模拟的 sample record，方便外部用户测试离线滤波。
- [ ] 在 release 页面说明当前版本的已知限制。
- [ ] 如果后续接入真实设备，补充硬件协议版本和兼容性说明。
- [ ] 如果引入第三方算法或数据集，补充来源和许可证。

## 发布后维护建议

- 优先处理会导致采集失败、数据格式不兼容、记录文件错误的问题。
- 算法参数调整要同时更新文档和测试。
- 对外接口字段变更应尽量保持兼容；确需破坏性变更时，在 README 和 release notes 中明确说明。
